# SWYNEX Interactive Dashboard

Task 3 of my SWYNEX Technologies internship. An interactive dashboard built on the
cleaned Titanic dataset from Task 1, using HTML, CSS and JavaScript.

**Live demo:** https://bist52t.github.io/SWYNEX-Interactive-Dashboard/

![Dashboard](screenshots/dashboard.png)

## Features
- 5 KPIs: passengers, survival rate, average age, median fare, average family size
- 6 charts: survival by sex, class, port, age group, family size and fare band
- Filters: sex, class, port, known-ages-only, plus click-to-filter on bars
- Everything updates together when a filter changes
